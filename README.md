# 奥术铁砧 JEI 优化

**Arcane Anvil JEI Optimization · 1.0.2**

减少大量法术附属带来的奥术铁砧 JEI 页面卡顿。按需创建当前页的配方布局，随后分批预加载附近页面，并逐步缓存当前查询的其他配方。最多保留 1,024 个布局，兼顾打开页面和连续翻页的体验。

## 安装与使用

| 依赖 | 支持版本 |
|---|---|
| Minecraft | 1.20.1 |
| Forge | 47.x（实测 47.4.20） |
| Iron's Spells 'n Spellbooks | 1.20.1-3.4.0.11 ～ 1.20.1-3.16.3 |
| JEI | 15.20.0.100 ～ 15.28.1.166 |

将 `arcane-anvil-jei-optimization-1.0.2.jar` 放入客户端 `mods`，重新启动游戏即可，服务器无需安装。

照常在 JEI 中查看武器、法术卷轴的用途，或打开奥术铁砧分类，无需额外设置。卸载时关闭游戏并移除 JAR。

## 使用说明

- 保留原配方、附属注入规则以及实际铁砧操作。
- 配方数量与页数保持原样，优化覆盖打开配方页面和翻页时的布局加载；进入世界时的 JEI 索引加载仍沿用原流程。
- 奥术铁砧分类按原配方顺序显示，不执行“收藏优先”和“可制作优先”排序；收藏能力沿用原版。其他分类不变。

当前版本支持上表列出的版本范围，暂不支持 JEI 15.28.1.167 及更新版本。
